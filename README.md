Team10_tkgd - E-commerce Website
Project Overview
This is an e-commerce website project built with HTML, CSS, and JavaScript. The website features product listings for various electronics brands including Huawei, iPad, iPhone, LG, Oppo, and Samsung.

Features
Product Pages: Dedicated pages for different product categories

huawei.html, ipad.html, iphone.html, lg.html, oppo.html, samsung.html

Product Details: chittet.html for detailed product information

Shopping Cart: car.html for managing purchased items

User Authentication: login.html for user login

Main Page: index.html as the homepage

Product Listing: product.html for general product display
