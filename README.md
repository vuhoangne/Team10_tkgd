# Team10_tkgd - E-Commerce Website  

🚀 **A responsive e-commerce website for electronics shopping**  

---

## 📌 Project Overview  
A multi-page static website built with:  
✔ **HTML5**  
✔ **CSS3**  
✔ **JavaScript**  
✔ **Bootstrap**  

---

## 🛠️ Features  
### 📱 Product Catalog  
| Page | Description |  
|------|-------------|  
| `huawei.html` | Huawei devices |  
| `iphone.html` | Apple iPhones |  
| `samsung.html` | Samsung products |  
| `product.html` | General product listing |  

### 🔍 Key Functionalities  
- `chittet.html` - Product details page  
- `car.html` - Shopping cart system  
- `login.html` - User authentication
